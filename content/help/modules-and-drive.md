# Modules and the Class Drive

## Modules

**Modules** has the lecture slides and practicum PDFs for each subject,
cleaned up (pages with personal details removed) and viewable in the app.

- Pick a subject. Its PDFs are grouped as **Lecture**, then **Practicum**
  (Reports, Assistance). A section marked "To be added" has nothing yet.
- Pick a PDF in the list to view it. **Open in new tab** opens it in your
  browser's own PDF viewer, which is often easier on a phone.
- A PDF is downloaded the first time you open it and then works offline.

## The Class Drive

The **Class Drive** is the class's shared Google Drive folder, live, inside the
app: every slide deck, recording, tutorial and exam file, folder by folder. It
needs an account: [sign in](/account) to see it.

### Finding files

- Folders open one level at a time; the path at the top takes you back up.
- **New this week** shows files added or changed in the last 7 days. A file
  stays "new" until you open it, and opened files get a small mark.
- Press <kbd>/</kbd> (or use **Find a file**) to search every file and folder
  name. <kbd>Esc</kbd> clears the search.
- Sort a folder **A–Z** or by **Newest**.

### Opening files

Files open in Google's own viewer inside the app. Use <kbd>←</kbd>
<kbd>→</kbd> (or the arrows) to step through the files in the folder,
**Download** to save one, and **Open in Drive** to open it in Google Drive.
<kbd>Esc</kbd> closes the viewer.

### Staying up to date

When files are added to or removed from the Drive, the app shows the change
within a few minutes. The listing opens instantly from your device's last
copy, then checks for changes. The status at the top says when it was last
updated; the refresh button beside it checks now.

### Linked folders

Some folders are linked from elsewhere in Google Drive, such as past cohorts'
**Pendproduktif**, and are marked "Linked folder". They can be large, so each
folder inside is read from Google Drive only when you open it: you'll see
"Loads when opened" under it, then a moment of "Reading this folder from
Google Drive…" the first time. After that it opens straight away on this
device, and the refresh button checks it for changes while you're inside it.

Search covers the folders you've opened so far; the search results say how
many linked folders haven't been opened yet.

### In the module pages

Each subject's page in **Modules** lists that subject's Drive files (under
**Class Drive**, marked _live_) above the cleaned PDFs, so slides and
recordings are next to everything else.

> The files belong to the class. Please don't rename, move or delete them from
> Google Drive: everyone sees the change.

## Which should I use?

The cleaned PDFs are fast and work offline. The Class Drive has everything,
including recordings and the newest uploads, but needs a connection.
