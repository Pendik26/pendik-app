# Modul dan Drive Kelas

## Modul

**Modul** berisi slide kuliah dan PDF praktikum setiap mata kuliah, sudah
dirapikan (halaman berisi data pribadi dihapus) dan bisa dilihat di aplikasi.

- Pilih mata kuliah. PDF-nya dikelompokkan sebagai **Lecture**, lalu
  **Practicum** (Reports, Assistance). Bagian bertanda "Akan ditambahkan" belum
  berisi apa pun.
- Pilih PDF di daftar untuk melihatnya. **Buka di tab baru** membukanya di
  penampil PDF bawaan browser, yang sering lebih nyaman di ponsel.
- PDF diunduh saat pertama kali dibuka, lalu bisa dibuka offline.

## Drive Kelas

**Drive Kelas** adalah folder Google Drive bersama milik kelas, selalu terbaru,
langsung di dalam aplikasi: semua slide, rekaman, tutorial dan file ujian,
folder demi folder. Fitur ini butuh akun: [masuk](/account) untuk melihatnya.

### Mencari file

- Folder dibuka satu tingkat demi satu tingkat; jalur di atas membawamu kembali
  ke atas.
- **Baru minggu ini** menampilkan file yang ditambahkan atau diubah dalam 7
  hari terakhir. File tetap "baru" sampai kamu membukanya, dan file yang sudah
  dibuka diberi tanda kecil.
- Tekan <kbd>/</kbd> (atau pakai **Cari file**) untuk mencari di semua nama
  file dan folder. <kbd>Esc</kbd> menghapus pencarian.
- Urutkan folder **A–Z** atau **Terbaru**.
- **Terakhir dibuka** (di halaman pertama Drive dan di Beranda) menampilkan file
  yang terakhir kamu buka.
- Kamu melihat folder kelasmu sendiri (IUP atau Reguler) dan folder bersama.
  Centang **Tampilkan folder kelas lain** untuk melihat folder mereka juga.

### Membuka file

File dibuka di penampil Google sendiri di dalam aplikasi. Pakai <kbd>←</kbd>
<kbd>→</kbd> (atau panahnya) untuk berpindah antar file di folder itu,
**Unduh** untuk menyimpan satu file, dan **Buka di Drive** untuk membukanya di
Google Drive. <kbd>Esc</kbd> menutup penampil.

### Selalu terbaru

Saat file ditambahkan ke atau dihapus dari Drive, aplikasi menampilkan
perubahannya dalam beberapa menit. Daftarnya langsung terbuka dari salinan
terakhir di perangkatmu, lalu memeriksa perubahan. Status di atas menunjukkan
kapan terakhir diperbarui; tombol segarkan di sampingnya memeriksa sekarang.

### Folder tertaut

Beberapa folder ditautkan dari tempat lain di Google Drive, seperti
**Pendproduktif** milik angkatan sebelumnya, dan ditandai "Folder tertaut".
Ukurannya bisa besar, jadi setiap folder di dalamnya baru dibaca dari Google
Drive saat kamu membukanya: kamu akan melihat "Dimuat saat dibuka" di bawahnya,
lalu sebentar "Membaca folder ini dari Google Drive…" saat pertama kali. Setelah
itu folder langsung terbuka di perangkat ini, dan tombol segarkan memeriksa
perubahannya selama kamu berada di dalamnya.

Pencarian mencakup folder yang sudah pernah kamu buka; hasil pencarian
menyebutkan berapa folder tertaut yang belum dibuka.

### Di halaman modul

Halaman setiap mata kuliah di **Modul** menampilkan file Drive mata kuliah itu
(di bawah **Drive Kelas**, bertanda _langsung_) di atas PDF yang sudah
dirapikan, jadi slide dan rekaman ada di samping materi lainnya.

> File-file ini milik kelas. Tolong jangan ganti nama, pindahkan atau hapus
> dari Google Drive: semua orang akan melihat perubahannya.

## Mana yang sebaiknya dipakai?

PDF yang sudah dirapikan cepat dan bisa offline. Drive Kelas berisi semuanya,
termasuk rekaman dan unggahan terbaru, tetapi butuh koneksi.
