# Image occlusion

Image occlusion is how anatomy figures are learned: an atlas figure with its
labels covered. One label is marked with a **red box**. Name it, reveal it, and
grade yourself. Every label has its own review schedule, exactly like a
[flashcard](/docs/flashcards).

## Review a figure

1. Open **Image Occlusion** and choose a subject.
2. Say (or think) the name of the label under the red box.
3. Tap the figure or press <kbd>Space</kbd> to reveal it.
4. Grade it with the buttons or <kbd>1</kbd>–<kbd>5</kbd>. Each button shows
   when that label will come back.

## Review or Browse all

- **Review** asks only the labels that are due, figure by figure. When it's
  done you'll see **Review done**.
- **Browse all** goes through every figure in order, so you can study a region
  from start to finish even when nothing is due.

In either mode, tap any box or numbered chip to ask that label next.

## Moving around

| Action | Keys | On a phone |
| --- | --- | --- |
| Previous / next label | <kbd>←</kbd> <kbd>→</kbd> | swipe |
| Previous / next figure | <kbd>Shift</kbd> + <kbd>←</kbd> <kbd>→</kbd> or <kbd>[</kbd> <kbd>]</kbd> | the figure arrows |
| Gallery of every figure | <kbd>G</kbd> | **All figures** |
| Show every label (study the figure whole) | <kbd>A</kbd> | **Show labels** |
| Hide every label, or only the one asked | <kbd>H</kbd> | **Hide all** |
| Zoom in on the label | <kbd>Z</kbd> | **Zoom** |
| Undo the last grade | <kbd>U</kbd> or <kbd>Ctrl</kbd> + <kbd>Z</kbd> | the undo arrow |

## The gallery

The gallery shows every figure with how far you've got. The label chips are
coloured: **new**, **due**, **learning** and **mastered**. Filter by body region
to focus on one part. The app picks up where you left off next time.

## Tips

- With **Hide all** on, every label is covered, so nearby labels can't give the
  answer away. Turn it off to cover only the label being asked, which is
  easier while you're first learning a figure.
- Use **Show labels** to read a figure once before you start testing yourself
  on it.
- **Read about this figure** opens the ebook chapter that covers it.
- Figures come from the practicum slides. If a label looks wrong, check the
  module PDF it came from.
